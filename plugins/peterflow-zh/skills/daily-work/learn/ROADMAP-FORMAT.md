# 路线讨论与整套备课

## 一起定路线

从用户想做到的事和已经会的内容出发。已有 `MISSION.md`、学习记录或用户给出的提纲时直接沿用，只问会改变起点、范围或难度的问题。

在会话中给出一个简短的有序草案。每节列出主题和一个可观察的学习成果，有前置关系时说明为什么这样排。让用户能直接指出哪节跳过、合并、调序或深入。收到修改意见就给出修订后的路线，等用户认可当前版本再生成课件。

## 确认后一次生成

用户说“按这版来”就可以开始。用户已经给出定稿并要求全部生成时，直接采用。若用户明确说本轮只定路线，就保存定稿，到这里结束。

1. 在教学工作区根目录将定稿写入 `ROADMAP.md`。写清学习起点和目标，按确认的顺序列出每节课的主题、学习成果。它同时是整套课的目录。
2. 在同一轮把路线上的课件备齐。复用已有资料、组件和仍符合学习成果的课程。新课沿用 `lessons/` 的下一个可用编号，各写成一个完整的 HTML 文件。每节都要有讲解、带反馈的练习、一手来源和相关参考资料链接。备课时连续生成后续各节，练习留给用户之后按自己的节奏完成。
3. 每生成或复用一课，就把实际文件的相对链接补回 `ROADMAP.md`。中途中断时从这份路线接续，核实已有课件，只补缺失或未完成的部分。交付前逐项核对课件能打开、内容对应约定的学习成果。整套齐备后给用户路线入口和起始课，需要打开时只打开起始课。

课件生成进度记在路线里。学习进度按[学习记录格式](./LEARNING-RECORD-FORMAT.md)单独记录，依据用户表现出的理解、自述的已有知识或其他符合记录条件的事实更新。
