# RESOURCES.md 格式

`RESOURCES.md` 汇集为这个主题挑选的可信来源。讲解知识时从这里取材，避免凭模型记忆猜测。用户可以到其中列出的社群积累实践智慧。

## 结构

```md
# {主题}的学习资源

## 知识

- [书籍《The Science and Practice of Strength Training》，Zatsiorsky 和 Kraemer 著](https://example.com)
  讲解训练计划编排和机体适应的基础著作。涉及训练周期、恢复或强度区间时查阅。
- [Greg Nuckols 的文章《How Much Should I Train?》，刊于 Stronger By Science](https://example.com)
  依据研究综述训练量的参考范围。为各肌群安排每周训练组数时查阅。

## 实践智慧（社群）

- [r/weightroom](https://reddit.com/r/weightroom)
  讨论质量高，版主管理严格，重视训练说法的依据。适合请人点评训练计划，或讨论如何突破瓶颈。
- 本地活动：{健身房名称}的周二力量训练课
  适合练习举重动作时获得教练的现场反馈。
```

## 写法

- **精选可信来源。** 优先选一手资料、公认的专家、经过同行评审的成果和管理良好的社群。剔除包装成教学内容的营销材料。
- **每条都加说明。** 三个月后再看，一个光秃秃的链接很难派上用场。加一行，说明这份资源讲什么、什么时候值得查。
- **按知识和实践智慧分组。** 分组与[教学理念](./SKILL.md)对应。一份资源只出现在其中一组就可以。
- **明确记下缺口。** 学习目标涉及的某个领域还没找到好资料时，添加 `## Gaps`（资料缺口）一节，列明缺什么，供以后继续查找。
- **淘汰低价值资料。** 已证实有误、内容肤浅或偏离学习目标的资源应当移除。五份切题的好资料比三十份平庸的资料更有用。
- **记录用户对社群的偏好。** 如果用户已表示不想加入社群，就记在这里，避免后续会话反复推荐。
