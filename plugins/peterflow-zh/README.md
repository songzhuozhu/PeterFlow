# PeterFlow · 中文单项 Skill

按原名选择中文 Skill。安装整套时使用同一目录并选择全部 21 项。

```sh
npx skills add https://songzhuozhu.github.io/PeterFlow/ --skill code-review
npx skills add https://songzhuozhu.github.io/PeterFlow/ --skill '*'
```
